# Cozy Spider

Браузерный пасьянс «Паук» с упором на атмосферу. Полный контекст проекта —
[cozy-spider-context.md](cozy-spider-context.md); про оживление сцены — §15.

**Игра играется.** Логика «Паука» с тестами, перетаскивание карт, живая
сцена из двенадцати слоёв с параллаксом: вода, ветер, дождь, атмосферный
пост, пламя в лампе, котик в пруду и кассетник на столе с рабочими
кнопками.

Колода проиллюстрирована: 22 своих лица из 52, остальные берут картинку
того же ранга из пик. Карты без картинки идут процедурными заглушками.

Рантайм-ассеты 6.9 МБ. Полный контекст — [CLAUDE.md](CLAUDE.md).

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:5173.

| | |
|---|---|
| Перетащить карту | зажать и вести |
| Альтернатива драгу | тап по карте, тап по цели |
| Раздать из запаса | клик по стопке справа внизу |
| Магнитофон | три клавиши на столе — назад, пуск, вперёд |
| **M** | сменить станцию: свет, дождь, ветер и виньетка меняются разом |
| **D** | счётчик fps и тира качества |

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер с hot reload шейдеров |
| `npm run build` | typecheck + прод-сборка в `dist/` |
| `npm run deploy` | сборка + выкладка фронта на VPS (cozyspider.ru), нужен SSH-ключ |
| `npm run deploy:api` | выкладка бэкенда (`server/`) и перезапуск сервиса `cozy-api` |
| `npm run typecheck` | только проверка типов |
| `npm run test` | тесты логики пасьянса |
| `npm run gen:assets` | перегенерировать процедурные текстуры |

Подключение готового арта:

```bash
python tools/slice_layers.py verify && python tools/slice_layers.py wire
```

```bash
python tools/wire_deck.py
```

Маска воды для плейсхолдер-сцены пересобирается отдельно:

```bash
python tools/make_water_mask.py
```

## Структура

```
src/core/       логика пасьянса: ноль зависимостей от DOM/Pixi, 40 тестов
src/engine/     рендер: сцена, фильтры, шейдеры, карты, тиры качества
src/app/        HUD поверх канваса
art/            исходники и референсы; art/_snapshots/ вне git
public/assets/  рантайм-ассеты, отдаются как есть
server/         бэкенд: Node без фреймворков + SQLite, живёт на VPS за nginx
tools/          генераторы ассетов и дев-плагины
```

Бэкенд в деве: `node server/index.mjs` (порт 8787), Vite проксирует `/api`
туда сам. База уедет в `%TEMP%`, если задать `COZY_DB`; по умолчанию путь
серверный, так что локально переменную задавать обязательно.

Сцена описывается данными: [`public/assets/scene/pond/scene.json`](public/assets/scene/pond/scene.json).
Поле `plannedLayers` — план нарезки; чтобы включить готовые слои, их
переносят в `layers`, код не меняется.

## Требования к окружению

- **Node.js.** Собрано и проверено на 18.14.2, поэтому взят Vite 5.
  Node 18 снят с поддержки — при переходе на 20+ имеет смысл поднять Vite
  до 6.3+ и убрать `@rollup/pluginutils` (он нужен только как фолбэк для
  фильтра `vite-plugin-glsl`, см. §15.10).
- **Python 3** с `numpy` и `pillow` — только для генерации ассетов, в
  рантайме не участвует.
- **Vitest 2**, а не 4: четвёртая требует Node 20.12+.

## Проверка внешнего вида

Дев-сервер поднимает эндпоинт `POST /__snapshot`, который пишет кадр в
`art/_snapshots/`. Удобно, чтобы смотреть результат правок шейдеров:

```js
const s = window.__stage
for (let i = 0; i < 180; i++) s.frame(16.667)
s.app.renderer.render(s.app.stage)
const c = s.app.canvas
const out = document.createElement('canvas')
out.width = c.width; out.height = c.height
out.getContext('2d').drawImage(c, 0, 0)
fetch('/__snapshot', { method: 'POST', body: JSON.stringify({ name: 'check.png', dataUrl: out.toDataURL() }) })
```

Снимать нужно **сам канвас**, а не `renderer.extract`. Extract работает по
границам сцены, а они выходят за вьюпорт на запас под параллакс: в кадр
попадает область, которой игрок не видит, и по краям появляются тёмные
полосы, которых на экране нет.

`window.__stage` доступен только в дев-режиме.
