Сюда кладутся готовые слои, привезённые с машины с GPU.

Требования (их проверяет verify):
  - PNG с альфа-каналом, без потерь
  - каждый слой во весь холст, НЕ обрезанный по содержимому
  - все слои одного размера
  - имена ровно как в scene.json -> plannedLayers

Первые три, с которых стоит начать:
  00-sky.png              всё, что дальше воды
  04-water.png            пруд
  09-leaves-right.png     передний план одним куском
  09-leaves-right.wind.png  маска жёсткости, серым: белое гнётся, чёрное стоит

Потом отсюда:
  python tools/slice_layers.py verify
  python tools/slice_layers.py wire
