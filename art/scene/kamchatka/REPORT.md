# Камчатка — нарезка выполнена

Всё считалось в ComfyUI 0.33.2 на RTX 5070 Ti (PyTorch 2.12.1+cu130, sm_120 —
ловушка 50-й серии не сработала, сборка уже под CUDA 13). Модель инпейнта —
`flux1-fill-dev-fp8`, CFG 1, негативный промпт пустой.

## Что сделано

**1. Мастер 1538×1022 → 2560×1600** (§2)

Аутпейнт Flux Fill `+47/+47` по ширине до 1632×1024, затем кроп до 1632×1020 —
это ровно 1.6, поэтому финальный ресайз строго равномерный, без растяжения.
Апскейл `4x-UltraSharp` (×4 → 6528×4080) и Lanczos вниз до 2560×1600: ровно
×2.55 по обеим осям. Окна хрущёвки не перерисовывались вообще — тайлового
SD-апскейла с денойзом не было, поэтому опасность из §2.2 не возникла.

Внутренняя часть кадра после аутпейнта возвращена из оригинала пиксель в
пиксель (блендинг только в 20 px у новых краёв) — VAE-круг не размыл сцену.

- `source.png` — финальный мастер 2560×1600
- `source-1538.png` — исходник, как просили в §2.3
- `source-sliced.png` — состояние мастера после всех вырезов (конец цикла §4)

**2. Маски** (§3) — 11 масок + 4 маски ветра, все 2560×1600.

Силуэты снимались `SAM3_Detect` (`sam3.1_multiplex_fp16`) — текстом и кликами;
горизонтальные страты собраны по верхним границам силуэтов, фронт — по
геометрии проёма (окно: x 518…2372, задняя кромка подоконника y 1390).
Кайма — `GrowMask 45` + гаусс 10, замерено: 47–48 px за контур.

Маски ветра — градиенты: у леса и кустов вверх по кроне, у плюща и цветущего
куста — по удалению от косяка и вниз по плети. Косяк, стена и фотокарточки —
чёрные.

**3. Нарезка** (§4) — цикл спереди назад, 10 инпейнтов, ~2 мин каждый.

После каждого шага результат клался поверх `source.png`, и следующий слой
резался уже из него.

Ловушка §4 сработала ровно как описано: на косяках Flux четыре прохода подряд
рисовал в дырку **новый косяк** вместо вида за окном. Вылечено так, как и
советует задание — штампом: дырка сначала заполняется соседними пикселями
(вид за окном зеркалится наружу через кромку проёма, полосы — вниз через свою
верхнюю границу, со сдвигом 17 px), и только потом Flux дорисовывает поверх
на denoise 0.72–0.80. С заготовкой модель уточняет, а не выдумывает.

**4. Извержение** (§5) — инпейнт готового мастера, не новая генерация.

`00-sky.erupt.png`: небо сначала перекрашивается арифметически — облака ловят
свет снизу пропорционально своей яркости, чистое небо только теплеет, звёзды
не трогаются, — затем Flux на denoise 0.42. Плоская заливка на 0.8, которую
пробовали сначала, смывала облака и давала вертикальный столб света; столб
пепла рисовать нельзя, он приедет спрайтом.

`01-volcano.erupt.png`: модель пущена **только на кратер и верхние склоны**
(эллипс вокруг вершины), остальной конус разогрет арифметикой. Поэтому силуэт
горы совпадает с обычным слоем пиксель в пиксель — при denoise 0.65 на всю
маску он заметно уезжал.

Приёмка §5.3 пройдена: при подмене обоих слоёв всё, кроме неба и конуса,
меняется ровно на 0.00.

## На что посмотреть

- **`reference-erupt.png` извержения не содержит.** Это спокойная сцена с
  котиком и кассетником; ни столба, ни красного неба, ни позы «смотрит на
  сопку» там нет. Сверить цвет по §5.2 было не с чем, поэтому взята умеренная
  трактовка: небо краснеет заметно, но не уходит в малиновую заливку.
- `source.png` в архиве — **полный мастер**, а не состояние после вырезов
  (§4 велит перезаписывать его на каждом шаге, §7 называет его «финальный
  мастер»). Итог цикла лежит рядом как `source-sliced.png`.
- Под плафоном лампы Flux оставил светлое пятно на месте самой лампы. Лампа и
  левый косяк оба на параллаксе 0.34, относительного сдвига между ними нет,
  так что пятно закрыто слоем лампы при любом положении камеры.
- Карандашница слева отмечена прямоугольником вручную: SAM на каждый клик в
  неё отдавал стойку лампы.
- Фоновые полосы (`01`…`05`) намеренно продлены вниз до низа проёма, а косяки
  сплошные в своих колонках — каждый дальний слой работает подложкой для
  ближних. Без этого при панораме открывались дырки до 46×36 px между листьями
  цветов у косяков.

## Инструменты

`tools/` — то, чем это считалось, через HTTP API ComfyUI (localhost:8188):

| Файл | Что делает |
|---|---|
| `comfy.py` | драйвер API: upload / queue / wait / fetch |
| `step1_outpaint.py`, `step2_restore_and_crop.py`, `step3_upscale.py` | мастер до 2560×1600 |
| `sam_probe.py`, `sam_pts.py` | силуэты SAM3 текстом и кликами |
| `build_masks.py`, `build_wind.py` | сборка 11 масок и 4 масок ветра |
| `prefill.py` | штамп: заполнение дырки соседними пикселями |
| `slice_layers.py` | `cut` / `heal` / `verify` |
| `run_slice.py` | цикл спереди назад целиком |
| `recut.py` | перерезать слои из сохранённых стадий без GPU |
| `erupt.py` | два вариантных слоя извержения |
| `preview.py` | сборка стопки слоёв с параллаксом для приёмки |

`python tools/slice_layers.py verify` проверяет размеры, альфу и имена.

побайтово совпадает с `source.png` (`md5 16cd013f…`), это и есть приёмка.

в `work/`.
