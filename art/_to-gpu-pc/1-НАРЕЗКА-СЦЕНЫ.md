# Нарезка сцены `pond` — рабочая инструкция

Открыть на машине с GPU. Всё, что здесь описано, делается один раз.

Цель: превратить одну плоскую картинку в 13 слоёв с прозрачностью.
Движение (вода, дождь, ветер, мерцание) уже написано в коде — от нейросети
нужны **только статичные слои**.

> Колода и котик — отдельное задание, см. `art/deck/DECK-AND-CAT.md`.
> Здесь только фон.

> **Видеомодели (AnimateDiff, WAN, SVD) не использовать.** Не потому что
> плохие, а потому что видеофон не умеет реагировать на игру: пламя из
> ролика не подсветит поднятую карту. Развёрнуто — §15.1 контекст-дока.

---

## 0. Железо и установка

RTX 5070 Ti, 16 ГБ VRAM — хватает на Flux Fill в fp8 с запасом.

**Ловушка 50-й серии.** Blackwell — это архитектура sm_120, ей нужен
PyTorch, собранный под CUDA 12.8. Симптом несовпадения:

```
CUDA error: no kernel image is available for execution on the device
```

Свежий ComfyUI Desktop ставит правильный torch сам. Если собираешь
вручную — ставить cu128, не cu121.

Ставить **Local**, не Cloud: Cloud это аренда чужих GPU, при своей 5070 Ti
она не нужна.

Обязательно поставить **ComfyUI Manager** — через него ставятся ноды и
модели, руками раскладывать файлы не придётся.

## 1.5 Стереть карты и интерфейс — ДО всего остального

На исходной картинке нарисованы карты, кнопки и счётчики. **Это не слой.
Это мусор, который надо убрать.**

Настоящие карты рисует код, HUD — это DOM поверх канваса. Если оставить
нарисованные, игрок увидит два комплекта карт сразу: настоящие поверх
пририсованных.

Убрать инпейнтом:

- десять колонок карт вверху
- стопку-запас справа вверху
- плашки «Паук», «Время / Ходы», «Новая игра», кнопки
- плашку «Счёт / Лучший» слева внизу

Под ними должен остаться **чистый пруд с берегами** — так, как будто карт
там никогда не было. Дырки крупные, но лёгкие: почти везде под ними вода и
листва, то есть ровная фактура без сюжета.

Это единственное место, где инпейнт обязан быть аккуратным: область в
середине кадра, её видно всегда.

Порядок именно такой — сначала очистка, потом расширение холста. Иначе
придётся вычищать ещё и то, что модель дорисует по краям, копируя карты из
центра.

---

## 2. Аутпейнт — первым делом

Исходник `low_fie.png` — 1402×1122, это ≈5:4. Игра должна жить и на 21:9,
и на телефоне, плюс параллаксу нужен запас за краем кадра.

**Расширить до 2560×1600. До нарезки, не после.** Иначе придётся
доращивать тринадцать слоёв по отдельности и на каждом ловить расхождение
стиля.

Расширение почти целиком горизонтальное. 2560×1600 это 4 мегапикселя —
Flux на такое за один проход идёт тяжело, поэтому:

1. расширить влево до нужной ширины,
2. отдельным проходом вправо,
3. добить по высоте.

По краям кадра только листва и вода, так что промпт простой — описание
сцены плюс «continuation of the scene, same style».

**Держать безопасную зону:** всё сюжетно важное (домик, лампа, кружка,
котик) должно остаться в центральных 1402×1122. Края — только фон.

---

## 3. Карта глубины

Прогнать готовый холст через Depth Anything V2 → сохранить как `depth.png`.

Даёт две вещи: видно, где проходят границы слоёв, и потом это же
используется для фейкового DOF.

## 4. Нарезка — строго спереди назад

Порядок обязателен. Если резать сзади вперёд, одну и ту же дырку придётся
восстанавливать по нескольку раз.

```
для каждого объекта, начиная с самого ближнего:
    1. маска по клику (SAM)
    2. сохранить объект по маске  -> слой с прозрачностью
    3. стереть его с холста, инпейнт дырки -> холст без объекта
    4. следующий объект
```

### Что режем

| Файл | Что попадает в слой |
|---|---|
| `13-glass.png` | стекло лампы |
| `11-lantern.png` | лампа без пламени |
| `10-table.png` | стол, блокнот, кружка |
| `09-leaves-right.png` | крупные листья справа |
| `08-flowers-left.png` | цветы и трава слева |
| `07-cat.png` | котик |
| `06-lilypads.png` | кувшинки, лотосы |
| `05-water-refl.png` | отражения на воде |
| `04-water.png` | поверхность пруда |
| `03-mid-foliage.png` | крона сверху, ветки |
| `02-house.png` | домик |
| `01-far-trees.png` | дальние деревья |
| `00-sky.png` | небо — то, что осталось |

### Что лучше перегенерировать, а не вырезать

**Котик и пламя.** Вырезанный из общей картинки котик будет с водой по
краям и без нижней половины. Оба генерируются отдельно — задание на котика
лежит в `art/deck/DECK-AND-CAT.md`, часть 2.

Из пруда котика при нарезке **стереть**, как карты: его слой приедет
отдельным файлом.

Пламя — отдельный спрайт-лист 12–16 кадров, сетка 4×4 в одном PNG.

### Дырки не обязаны быть идеальными

Область за большим листом справа при сдвиге камеры открывается на 20–30
пикселей. Никто не увидит, что там дорисовано криво.

Генеративная заливка реально нужна для двух-трёх больших дыр: за столом и
за передними листьями. Дырки за кувшинками и котиком закрываются штампом
за минуту.

## 5. Требования к экспорту

Это важнее качества дорисовки — тут ошибка ломает раскладку.

1. **PNG с альфа-каналом.** Не JPEG.
2. **Каждый слой — во весь холст 2560×1600.** Не обрезать по содержимому.
   Все слои должны быть одного размера, иначе они разъедутся: движок
   ставит их в одну точку и масштабирует одинаково.
3. **Имена — точно как в таблице.** Без пробелов и кириллицы.
4. **Не жать с потерями.** PNG lossless.

### Маски ветра

Для слоёв с листвой нужен ещё один файл: `NN-имя.wind.png` — одноканальная
маска жёсткости в том же размере.

- **белое** — гнётся сильно (край листа, верхушка травы)
- **чёрное** — стоит неподвижно (ствол, основание куста)
- градиент между ними

Рисуется мягкой кистью за пару минут, нейросеть не нужна.

Нужны для: `01-far-trees`, `03-mid-foliage`, `08-flowers-left`,
`09-leaves-right`.

---

## 6. Куда класть и как подключить

Готовые слои сложить в `art/scene/pond/layers/`, затем:

```bash
python tools/slice_layers.py verify
```

Скрипт проверит размеры, альфу и имена, а потом:

```bash
python tools/slice_layers.py wire
```

перенесёт слои в `public/assets/scene/pond/` и перепишет `scene.json` —
`plannedLayers` станут активными `layers`. Код рендера при этом не
меняется вообще.

---

## 7. Начать с трёх слоёв, а не с тринадцати

Первый заход:

```
00-sky.png            всё, что дальше воды
04-water.png          пруд
09-leaves-right.png   весь передний план одним слоем
```

Полдня работы, и сразу видно, оживает ли сцена от параллакса. Тринадцать
слоёв имеет смысл резать, только когда убедишься, что подход работает.
