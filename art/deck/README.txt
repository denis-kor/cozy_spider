Иллюстрации колоды.

  figures/S11.png   валет пик       S пики, H червы, D бубны, C трефы
  figures/S12.png   дама пик        11 валет, 12 дама, 13 король
  figures/S13.png   король пик
  ...               всего 12 файлов
  back.png          рубашка

Генерируется ТОЛЬКО содержимое окошка. Рамку, угловые индексы и знак
масти рисует код — модели не умеют надёжно рисовать текст, и «K» на
сгенерированной карте окажется мусором.

Размеры:
  figures/*.png   1024x832   (соотношение 1.23, окошко на карте)
  back.png         768x1114  (соотношение 0.69, всё поле рубашки)

Подключение:
  python tools/wire_deck.py --check    только проверить пропорции
  python tools/wire_deck.py            проверить и подключить

Класть можно по одной: карты без картинки остаются на заглушках,
игра работает.
