## Задание 1. Колода: 52 лица

Сейчас в игре 12 из 52. Остальные 40 идут бумажными заглушками с пипсами —
не сломаны, просто картинок нет.

### Формат

| | |
|---|---|
| Размер | **512×742** |
| Соотношение | 0.69 — это пропорции карты |
| Формат | PNG |
| Текста в картинке | **нет** |

Картинка занимает карту **целиком**, край в край. Ранг и масть рисует код
поверх неё.

### ⚠️ Держать углы пустыми

Код кладёт в левый верхний и правый нижний углы непрозрачные уголки с
рангом. Они занимают примерно **30% ширины и 25% высоты** карты.

```
┌────────┬─────────────┐
│ уголок │             │
├────────┘             │
│                      │
│      сюжет сюда      │
│                      │
│             ┌────────┤
│             │ уголок │
└─────────────┴────────┘
```

Что попадёт под уголки — не увидят. Главный мотив держать в центре, по
углам оставлять небо, воду, туман — что угодно спокойное.

### Что рисовать

Маленькие пейзажи в стиле сцены пруда. Не геральдические фигуры.

| Масть | Настроение |
|---|---|
| ♠ пики | ночь, дождь, холодная синь |
| ♥ червы | тёплый вечер, огонь, янтарь |
| ♦ бубны | утро, туман, рассвет |
| ♣ трефы | лес, зелень, день |

Внутри масти сюжет растёт по рангу: **двойка** — деталь у воды, веточка,
камень; **король** — большой пейзаж целиком. Тогда старшинство читается
раньше, чем игрок посмотрит на уголок.

### Как держать стиль

- **Одна масть — один заход.** Между сессиями уплывают seed и веса, и
  разнобой видно.
- Стиль тянуть с картинки пруда через **IP-Adapter**.
- Промпт-шаблон один, меняется только сюжет:

```
<сюжет>, studio ghibli style, soft painterly, muted palette,
gentle light, vertical composition, empty sky in top left corner
```

Негатив обязательно:

```
text, letters, numbers, watermark, signature, border, frame, playing card
```

Без `playing card` в негативе модель начнёт сама дорисовывать рамку и
цифры, поверх которых лягут наши.

### Список файлов

`art/deck/faces/` — 52 штуки, S пики, H червы, D бубны, C трефы:

```
S1 S2 S3 S4 S5 S6 S7 S8 S9 S10 S11 S12 S13
H1 H2 H3 H4 H5 H6 H7 H8 H9 H10 H11 H12 H13
D1 D2 D3 D4 D5 D6 D7 D8 D9 D10 D11 D12 D13
C1 C2 C3 C4 C5 C6 C7 C8 C9 C10 C11 C12 C13
```

Туз это `1`, валет `11`, дама `12`, король `13`.

**Двенадцать уже существующих** (`*11`, `*12`, `*13`) сгенерированы
горизонтальными 1024×832 — им срезает бока. Перегенерировать в 512×742.

**Начинать с пик.** Тринадцать пиковых закрывают лёгкий режим целиком —
можно посмотреть полную колоду вживую до того, как рисовать остальные 39.

### Подключение

```bash
python tools/wire_deck.py --check
python tools/wire_deck.py
```

`--check` показывает, чего не хватает. Класть можно по одной.

## Задание 2. Фон: 13 слоёв вместо трёх

Сейчас весь передний план — один кусок. Стол, лампа, дальние деревья ездят
с одной скоростью, и параллакс работает в четверть силы. Ради этого вся
нарезка и затевалась.

### Исходник

`_canvas-2560x1600.png` — очищенный холст, из него режется всё. Карты, HUD
и котик с него уже стёрты.

Три существующих слоя — первый заход, их тоже надо перерезать: `00-sky`
сейчас содержит и небо, и деревья, и домик.

### Порядок: строго спереди назад

```
для каждого объекта, от самого ближнего к дальнему:
    1. маска (SAM)
    2. сохранить объект по маске  -> слой с прозрачностью
    3. стереть его, инпейнт дырки -> холст без объекта
    4. следующий
```

Наоборот нельзя: одну дырку придётся восстанавливать по нескольку раз.

### Слои

| Файл | Что | Параллакс |
|---|---|---|
| `13-glass.png` | стекло лампы | 0.34 |
| `11-lantern.png` | лампа без пламени | 0.34 |
| `10-table.png` | стол, блокнот, кружка | 0.32 |
| `09-leaves-right.png` | крупные листья справа | 0.28 |
| `08-flowers-left.png` | цветы и трава слева | 0.22 |
| `06-lilypads.png` | кувшинки, лотосы | 0.14 |
| `05-water-refl.png` | отражения на воде | 0.10 |
| `04-water.png` | поверхность пруда | 0.10 |
| `03-mid-foliage.png` | крона сверху, ветки | 0.08 |
| `02-house.png` | домик | 0.04 |
| `01-far-trees.png` | дальние деревья | 0.02 |
| `00-sky.png` | небо — то, что осталось | 0.00 |

`07-cat` не режется: котик уже отдельным файлом.

### Дырки не обязаны быть идеальными

Область за листьями при сдвиге камеры открывается на 20–30 пикселей.
Аккуратный инпейнт нужен для двух-трёх больших дыр — за столом и за
передними листьями. За кувшинками закрывается штампом за минуту.

### Требования к экспорту

Это важнее качества дорисовки: тут ошибка ломает раскладку.

1. **PNG с альфа-каналом**
2. **Каждый слой во весь холст 2560×1600**, не обрезать по содержимому
3. **Все слои одного размера** — иначе разъедутся
4. Имена точно как в таблице

### Подключение

```bash
python tools/slice_layers.py verify
python tools/slice_layers.py wire
```

## Задание 3. Маски ветра

Четыре штуки, к слоям листвы:

```
01-far-trees.wind.png
03-mid-foliage.wind.png
08-flowers-left.wind.png
09-leaves-right.wind.png
```

2560×1600, оттенки серого:

- **белое** — гнётся сильно: край листа, верхушка травы, кончик ветки
- **чёрное** — стоит: ствол, основание куста, стол, лампа, кружка
- градиент между ними

Нейросеть не нужна — мягкая кисть, пара минут на маску. Перекладку серого
в альфу берёт на себя `wire`.

Одна такая маска уже есть (`09-leaves-right.wind.png`), посчитана
автоматически. Её стоит пройти кистью: автомат не знает, что ствол не
гнётся.

## Чего на том компьютере делать НЕ надо

**KTX2-сжатие** — это шаг сборки, а не генерация. Делается здесь, на
готовых PNG.

**Звук** — не генерация картинок. Отдельная история: либо заказ у
продюсера, либо процедурный lo-fi на Tone.js (§7 контекст-дока).
