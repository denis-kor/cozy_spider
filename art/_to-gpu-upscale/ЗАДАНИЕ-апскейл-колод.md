# Задание 5: апскейл карт до 1024

Карты на больших мониторах упираются в разрешение мастеров: все лица
сгенерены в 512×742, и конвейер уже выжимает из них всё (мипмапы,
атлас в 2x). Больше пикселей можно взять только из новых мастеров.

**Нужно: те же картинки в 1024×1484.** Не новые сюжеты — апскейл
готовых. Исходники у тебя уже есть (это то, что ты генерил).

## Что прогнать

| Набор | Файлы | Приоритет |
|---|---|---|
| Таро | `deck-tarot/faces/S1..C13.png` — 52 шт. | **первый**: там тонкая гравюра, ей хуже всех |
| Таро рубашка | `deck-tarot/back.png` 768×1112 → 1536×2224 | вместе с таро |
| Пруд | `deck/faces/*.png` — 16 шт. (тузы и фигуры) | вторым, по остатку сил |

Числовые пруда не нужны — они процедурные и в манифест не входят.

## Чем

В ComfyUI любой приличный апскейлер ×2:

- **4x-UltraSharp** или **SwinIR** с даунскейлом до ×2 — для живописных
  (пруд и фигуры таро)
- для гравюрных числовых таро хорошо держит линию и обычный ×2 без
  фанатизма; главное — без «пластика» и дорисованных деталей

Никакого img2img с denoise: сюжет должен остаться пиксель в пиксель,
только чётче. Если апскейлер начинает фантазировать (новые веточки,
изменённые лица) — снизить силу или сменить модель.

## Формат

- PNG, **1024×1484** (рубашка 1536×2224), имена ТЕ ЖЕ
- Никаких новых полей/рамок: вход 512×742 → выход ровно ×2

## Куда

Архивом обратно те же пути:

```
art/deck-tarot/faces/*.png   art/deck-tarot/back.png
art/deck/faces/*.png
```

Подключение на основной машине (уже готово, просто для истории):

```bash
python tools/wire_deck.py --deck tarot --numeric --no-index --max-width 1024
python tools/wire_deck.py --max-width 1024
```
