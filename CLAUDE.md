# Cozy Spider

Браузерный пасьянс «Паук» с упором на атмосферу. Продаётся ощущением, а не
механикой: логика тривиальна и всем известна, ценность в подаче.

**Порядок вложения сил: арт → тайминги анимаций → звук → шейдеры.**

### Осталось

1. **Тузы** бубён и треф. Числовым 2..10 картинки больше не нужны —
   они всегда классические пипсовые (генерить их не надо)
2. **9 фигурных** червей/бубён/треф перегенерировать: они горизонтальные
   1024×832, им срезает бока
3. **Звук** — винил, дождь, микшер (§7). Полдня, 60% эффекта. Кнопки
   магнитофона уже играют бесплатные lo-fi стримы (`src/app/radio.ts`),
   это временный слой до своего контента
4. Маски ветра пройти кистью: автомат не отличает ствол от листвы

## Как устроено

```

src/engine/    рендер: сцена, слои, акторы, фильтры, шейдеры, карты
src/app/       HUD поверх канваса, DOM
art/           исходники и мастера. В git не идут, см. art/.gitignore
public/assets/ рантайм: WebP + манифесты
tools/         генераторы ассетов и подключалки, Python
```

### Правила, которые держат архитектуру

**Логика не ждёт анимацию.** Ход меняет состояние мгновенно и возвращает
семантические события (`cardsMoved`, `dealt`, `runCompleted`). Рендер
подписан и превращает их в таймлайны. Ветки «а вдруг ход не пройдёт» в
анимациях быть не может.

**Отмена — реплей от сида,** а не обратные команды. Сохранение это
`{seed, suits, moves[]}`, пара килобайт.

**Один огонь на всю сцену.** Всё, что мигает, читает `Ambience.flicker`.
Пламя, гало лампы, блик на воде, экспозиция кадра, индикатор магнитофона —
одно значение. Независимые таймеры рассыпают сцену на несвязанные эффекты.

**Карты внутри `world`, а не поверх.** Поэтому атмосферный проход ложится и
на них. HUD — снаружи: зерно и виньетка на цифрах читаются как грязь.

**Сцена описана данными.** `public/assets/scene/pond/scene.json`: слои,
параллакс, эффекты, акторы, свет. Новый арт подключается заменой файла и
чисел, код не трогается.

## Подключение арта

```bash
python tools/slice_layers.py verify && python tools/slice_layers.py wire
python tools/wire_deck.py
```

`wire_deck.py --check` показывает, каких лиц не хватает. Оба скрипта сами
переводят в WebP и правят манифест.

Дополнительно:

- `tools/cutout_tape_deck.py` — вырезать предмет с белого фона и замерить
  его части, если арт пришёл JPEG без альфы
- `tools/gen_procedural_assets.py` — тайлящиеся текстуры, генерятся кодом
- `tools/make_water_mask.py` — маска воды для плейсхолдера

## Проверка внешнего вида

Дев-сервер поднимает `POST /__snapshot`, кадр падает в `art/_snapshots/`.

**Снимать `s.app.canvas`, а не `renderer.extract`.** Extract работает по
границам сцены, а они выходят за вьюпорт на запас под параллакс: в кадр
попадает то, чего игрок не видит, и по краям появляются тёмные полосы,
которых на экране нет (§17.4).

`window.__stage` доступен в дев-режиме. Котика можно вызвать вручную:
`__stage.scene.actor('cat').cat.surfaceNow()`.

## Ловушки, стоившие времени

Полный список — §13 контекст-дока. Самые дорогие:

- **Слои приходят с каймой 45 px за контуром.** Не обрезать: она закрывает
  щели между слоями при параллаксе (§18.2)
- **Альфу не жать с потерями** даже в WebP. Здесь это геометрия, не цвет
- **У Flux негативный промпт не работает вообще** — CFG 1, отрицания
  игнорируются. Описывать нужное позитивно (§18.5)
- **Инпейнт упирается в здравый смысл модели.** Блокнот со стола Flux
  четыре раза заменил новой книгой; убрали копированием досок со сдвигом
  на 170 px вниз (§19.6)
- **Зоны нажатия предметов сцены — поверх стола.** У стола область
  попадания на весь экран, кнопки под ним не получают кликов (§19.2)
- **`vite-plugin-glsl` на Vite < 6.3** без `@rollup/pluginutils` молча
  трансформирует все файлы проекта, включая `main.ts`. Симптом: приложение
  не стартует, в консоли пусто (§15.10)
- **Top-level await в `main.ts` дедлочит прод-сборку.** Ядро Pixi
  бандлится в один чанк с main; `app.init` динамически импортирует чанк
  окружения (browserAll), который импортирует ядро из чанка main — а тот
  стоит на await. В деве не воспроизводится. Симптом тот же: тишина без
  ошибок. Поэтому запуск обёрнут в `async function main()`

## Окружение

- **Node 18.14.2** — отсюда Vite 5 и Vitest 2. Vitest 4 требует Node 20.12+
- Python 3 с numpy, PIL, scipy — только для ассетов
- Второй компьютер с RTX 5070 Ti для генерации. Blackwell это sm_120,
  нужен PyTorch под CUDA 12.8

## Рабочий цикл с артом

Генерация идёт на втором компьютере, проект живёт здесь. Обмен архивами:
задание туда, PNG обратно. Заготовки заданий — в `art/*.zip`.

Игра обязана запускаться и играться **без единой картинки**: всё, чего нет,
подменяется процедурной заглушкой. Это не «пока нет арта», а рабочий
запасной путь.
